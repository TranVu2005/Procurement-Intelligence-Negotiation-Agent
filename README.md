# Procurement Intelligence & Negotiation Agent — Nội thất

Dự án cuối khóa AI Guru AEF1. Xem chi tiết setup, kiến trúc, hợp đồng interface
giữa 3 module tại [PROJECT-SETUP.md](PROJECT-SETUP.md).

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # điền ANTHROPIC_API_KEY
python src/agent.py
```
